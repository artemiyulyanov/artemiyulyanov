## 🚀 Избранные проекты

### 📖 [book-storage-system](https://github.com/artemiyulyanov/book-storage-system)

Микросервисная система на Go: монолитный CRUD переработан в независимые сервисы.

- 5 сервисов: `api-gateway`, `auth-service`, `user-service`, `book-service`, `event-service`
- Database-per-service на PostgreSQL, миграции через `golang-migrate`
- JWT-аутентификация на gateway, межсервисное взаимодействие по gRPC + Protobuf
- Асинхронная аналитика: Kafka → ClickHouse с батчингом и коммитом offset после успешной вставки
- Multi-stage Docker-сборки, Docker Compose

### 🏗 Сайт с CRM-интеграцией (ООО ТДС)

Frontend на React 19 + TypeScript и Python-сервис на FastAPI, который принимает заявки и создаёт лиды в amoCRM. Сборка и развёртывание: multi-stage Docker (Node → nginx), docker-compose.

### 🛒 Экосистема Telegram-магазинов (MX Team)

Production-система на Kotlin для блогеров и стримеров с аудиторией 500 000+ подписчиков. Устранил критическое узкое место (кэширование в Redis вместо полного перебора 10 000+ записей), настроил балансировку на Nginx, внедрил автовыдачу заказов. Результат: **+12% продаж и +24% оборота**.
